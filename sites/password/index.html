MIRTE Password Change

The new password will be used to log in to the robot's web services, SSH and the robot's WiFi network. Username is always mirte.
Only letters, numbers and - and _ characters are allowed. The new password must be at least 8 characters long.
If you haven't changed the password yet, you need to do it before you can access the robot's services from external IPs.
Default (old) password is mirte_mirte.
